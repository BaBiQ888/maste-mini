# 算本 · Brand Spec（方向 B · 纸本练习本）

| 字段 | 内容 |
|------|------|
| 产品名 | **算本** |
| 定位 | 3–6 年级数学培训 · 老师 + 学生 |
| 视觉方向 | 纸本练习本：暖米底、铁锈橙单 accent、克制留白 |
| 状态 | Phase 1 定稿（2026-07-25） |
| 来源 | 用户选定 B；logo 自研 |

---

## 气质

温和、低压力、适龄；像翻开一本干净的口算本，而不是游戏厅或 SaaS 仪表盘。

**关键词**：纸张 · 铅笔痕迹 · 格子 · 完成勾选 · 不催不闹  

**禁忌（反 slop）**：紫渐变、霓虹 glow、emoji 当图标、彩虹徽章、金币排行、左彩条卡片堆。

---

## Logo

| 资产 | 路径 |
|------|------|
| 主标（SVG） | `design/assets/logo.svg` |
| 仅图形 mark | `design/assets/logo-mark.svg` |
| 反白（深底用） | `design/assets/logo-on-dark.svg` |

**概念**：一本微开的练习册 + 页角折痕 + 装订点；封面上**几何化「算」字**点题；右上锈橙铅笔；底部墨绿完成勾。不画卡通小孩、不画复杂公式。

**变体**
| 用途 | 文件 |
|------|------|
| App 图标 / 登录 mark | `logo-mark.svg` · `miniprogram/assets/logo-mark.png` |
| 横版主标 | `logo.svg` |
| 深色底 | `logo-on-dark.svg` |
| 预览页 | `design/logo-preview.html` |

**安全区**：mark 四周 ≥ 0.2× 高度空白。  
**最小尺寸**：mark ≥ 24px；横版 wordmark ≥ 72px 宽。  
**错误用法**：拉扁、加紫渐变描边、改成立体拟物。

## 字体

| 角色 | 方案 |
|------|------|
| 中文 UI | 系统：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif` |
| 数字/口算 | `tabular-nums`；略加大字重 |
| 展示/品牌 | Logo 用 SVG 字形；正文不引入花哨 web 字体（小程序包体） |

层级：页面标题 20–22px medium · 正文 15–16px · 辅助 12–13px · 数字强调可 28–32px

---

## 圆角与间距

- 卡片：`12px`（不是 24 的「泡泡」）
- 主按钮：`10px`，高度 48
- 列表行：上下 14–16，左右 16–20
- 页面边距：16–20
- 模块间距：12 / 20 / 28 三档

---

## 组件签名（方向 B）

1. **纸感底**：全页 `--paper`，非纯白。  
2. **细横线**：列表/作业区可用 1px `--line` 模仿本子行线（opacity 低）。  
3. **完成勾选**：空心方框 → 锈橙实心对勾，不用星星爆炸。  
4. **主按钮**：满宽锈橙底白字；次按钮描边墨色浅底。  
5. **空状态**：一句人话 + 一个主操作，不堆插图。
