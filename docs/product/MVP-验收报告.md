## 1. 结论

**后端核心业务域与主路径自动化验收通过**，具备「老师建班布置三类作业 → 学生完成/订正/拍照 → 老师汇总催交与批改」闭环能力，可作为**机构内试用**版本。

小程序 UI 需在微信开发者工具按 [MVP-验收清单.md](./MVP-验收清单.md) 做一次手工走查（真机需配置 `apiBase`）。

## 4. 主路径脚本（自动化等价）

`server/tests/mvp-main-path.test.ts`：

```
登录老师/学生 → 建班 → 双生入班
→ 每日计算 + 知识点打卡 + 拍照
→ 学生完成计算 / 打卡订正 / 拍照提交
→ 老师批改拍照
→ 汇总 + 催交（未做学生在名单）
```

---

## 5. 已知非阻塞项

见 [MVP-验收清单.md](./MVP-验收清单.md) §D。摘要：

- 正式微信登录需配置 AppId/Secret  
- 真机联调改 `apiBase`  
- 限时交卷依赖客户端存活  
- 分数不做数学等价（如 1/2 与 0.5）  
- 订阅消息催交不在 MVP

## 6. 建议上线检查

1. 配置 `WECHAT_APPID` / `WECHAT_SECRET`，关闭 mock  
2. HTTPS 与小程序合法域名  
3. 数据目录持久化（`DATA_DIR` / SQLite 备份）  
4. 手工清单 C 节全勾  
5. 试运行 1 个真实班级一周，收集错题与出题反馈
